# EARN777 Phase 3 — Connected UI

## Run
1. Install Node.js 20+.
2. Open a terminal in `server`.
3. Run `npm install`.
4. Set `SESSION_SECRET`, `ADMIN_EMAIL`, and `ADMIN_PASSWORD` environment variables.
5. Run `npm start`.
6. Open `http://localhost:3000`.

The UI now includes Login, Signup, Tasks and an Admin Dashboard connected to the existing API.

Security note: this is still a development starter. Before handling real money, add HTTPS, secure production cookies, CSRF protection, rate limiting, email verification, audit logs, input validation, fraud controls, backups, and a compliant payment provider. Demo balances must not be treated as real funds.
